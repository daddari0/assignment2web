Task 3: Three Layouts, One Markup

12 articles displayed in three modes by changing a single class on the container • HTML untouched

Layout Mode: 1. Grid of Cards 2. Compact List 3. Magazine Front Page
Mode 1 (Grid of Cards): CSS Grid's repeat(auto-fit, minmax(min(100%, 240px), 1fr)) dynamically controls responsive column calculation based on window width, while inner Flexbox distributes card content and anchors metadata to the baseline.
Mode 2 (Compact List): CSS Grid stacks each article into a single-column row sequence, while inner Flexbox arranges the thumbnail on the left, expands the text body in the center, and pins the date to the far right edge via margin-left: auto.
Mode 3 (Magazine Front Page): CSS Grid's grid-auto-flow: dense with grid-column/row: span 2 commands the prominent hero article placement while seamlessly packing subsequent articles around it, supported by inner Flexbox for card component styling.
